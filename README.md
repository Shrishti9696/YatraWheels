# YatraWheels

> AI-powered vehicle booking and travel planning marketplace for India.

# Official site link- https://yatra-wheels--shrishtiyadav38.replit.app

## Tech Stack

**Frontend** — React 18 + Vite + Tailwind CSS v4 + Framer Motion  
**Backend** — Express 5 + MongoDB + JWT + Razorpay  
**AI** — OpenAI GPT-4o-mini (AI Travel Planner & YatraBot)

## Roles
- **User** — Browse fleet, book vehicles, AI travel planning
- **Vendor** — List vehicles, manage bookings & earnings
- **Driver** — View assignments, track trip status
- **Admin** — Full platform oversight

## Structure
```
frontend/   → React + Vite web app
backend/    → Express API server
lib/        → Shared TypeScript libraries
```
